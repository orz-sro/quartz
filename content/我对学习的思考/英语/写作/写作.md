## 一、写作本质

### 1.1 两大能力

- **造句能力**：用正确语法写出完整句子
- **谋篇能力**：按段落功能组织内容

### 1.2 模板与原创的关系

- 模板句解决作文 **60%** 的框架
- 自己填写的 A 和 B 占 **40%**，也是错误高发区
- 背模板 ≠ 会写作，关键在理解逻辑后灵活替换

### 1.3 改错的价值

- 自己写的错误往往自己发现不了
- 通过看别人作文，提前规避同类错误
- 真正提分来自“会写 + 少错”，而非堆砌复杂句

## 二、审题

### 2.1 英语一图画作文

- 抓核心元素：人物动作、表情、文字提示
- 定位寓意：现象 / 品质 / 社会问题
- 避免过度解读和极端立场

### 2.2 英语二图表作文

- 抓整体趋势：上升 / 下降 / 波动 / 稳定
- 抓关键数据：起点、终点、极值、倍数
- 抓对比关系：不同组别之间的差异

### 2.3 三类命题方向

| 类型 | 特征 | 写作重点 |
|------|------|----------|
| 正面现象 | 积极、值得提倡 | 分析意义 + 呼吁发扬 |
| 负面现象 | 需要警惕的问题 | 分析危害/原因 + 提出建议 |
| 正反双面 | 事物本身无绝对好坏 | 辩证分析 + 给出中肯态度 |

## 三、三段式结构

### 3.1 总体框架

```
第一段：描述
第二段：分析
第三段：总结
```

### 3.2 第一段 · 描述

**图画作文**

- 整体场景 1 句
- 核心细节 1-2 句
- 揭示寓意 1 句

**图表作文**

- 图表主题/类型 1 句
- 整体趋势 1 句
- 关键数据/极值 1-2 句

### 3.3 第二段 · 分析

**常见切入角度**
- 社会因素
- 科技因素
- 环境因素
- 个人/思想因素

**段落内部结构**
- 主题句
- 论据句：原因 / 例子 / 数据 / 道理
- 回扣句：回到主题

### 3.4 第三段 · 总结

**可选方向**
- 重申观点
- 提出建议
- 展望未来
- 强调意义

## 五、语言升级方向

### 5.1 词汇层

- 避免基础词重复：important / think / good / bad
- 按话题积累高频词：科技、环境、文化、教育、经济
- 注意词性：名词 / 动词 / 形容词 / 副词不能混用

### 5.2 句式层

- 主语从句
- 定语从句
- 状语从句
- 非谓语动词
- 倒装 / 强调 / 虚拟

### 5.3 逻辑层

- 句间衔接：转折、因果、递进、让步
- 段间过渡：承上启下
- 避免逻辑断层

## 六、常见错误地图

### 6.1 词性错误

- 名词当形容词用
- 动词形式错误
- 可数名词单复数问题

### 6.2 搭配错误

- 介词搭配
- 动词搭配
- 固定短语误用

### 6.3 语法结构错误

- there be 后接完整句子
- however / nevertheless 当连词用
- 逗号拼接两个完整句

### 6.4 中式英语

- 直译中文表达
- 忽略英语逻辑
- have / there be 混淆

### 6.5 指代与冠词

- the 泛指
- it / this 指代不清
- 可数名词裸用

## 七、训练路径

### 7.1 第一阶段：拆句练习

- 每个句型写 3 个以上不同主题句子
- 重点检查自己填写的 A 和 B
- 不追求复杂，先追求正确

### 7.2 第二阶段：段落练习

- 单独练习描述段、分析段、总结段
- 限时完成，模拟考场节奏

### 7.3 第三阶段：整篇练习

- 每周 1 篇大作文 + 1 篇小作文
- 优先用近 10 年真题
- 写完后对照范文，修正语言与逻辑

### 7.4 长期积累

- 整理个人高频错误清单
- 积累话题词汇和论据素材
- 背诵个性化模板句，避免千篇一律
