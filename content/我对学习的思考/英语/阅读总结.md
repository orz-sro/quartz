# 词性判断（阅读核心能力）

> [!danger] 只记意思不记词性 = 读不懂也写不出
> 词性决定用法。记单词必须记词性。

## 四种判断方法

| 方法 | 操作 | 例子 |
| --- | --- | --- |
| <font color="#79c0ff">语法位置</font> | 定语从句需要谓语 → 不认识的词是动词 | `lessons that zen` → zen 是动词 |
| <font color="#79c0ff">词形</font> | -ed 无 be 动词 → 非谓语作后置定语 | `lessons written/sent` → 修饰 lessons |
| <font color="#79c0ff">固定词性</font> | 倍数是副词，修饰动词 | `earn one-fifth as much` → one-fifth 修饰 earn |
| <font color="#79c0ff">介词短语</font> | up to / off / along 是介词短语，不能直接作谓语 | `they are up to scratch`（不能少 be） |

## 关键提醒

- `the + 最高级 + ___` → 空格必是名词（可名物化）

- 介词短语只有两个功能：<font color="#7ee787">修饰名词</font> 或 <font color="#7ee787">修饰动词</font>，通过意思判断修饰谁

- 介词短语作表语必须加 be 动词
