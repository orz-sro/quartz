## 一、史纲整体框架（徐涛课前引入）

### 两个时期
- **近代**：1840—1949（两半社会）
- **现代**：1949—至今

### 三个国情
| 时期 | 国情 |
|------|------|
| 近代 | 半殖民地半封建社会 |
| 1949—1956 | 新民主主义社会 |
| 1956—至今 | 社会主义初级阶段 |

### 五个阶段
| 时期 | 时间 | 阶段 |
|------|------|------|
| 旧民主主义革命 | 1840—1919 | 资产阶级领导 |
| 新民主主义革命 | 1919—1949 | 无产阶级领导 |
| 社会主义革命 | 1949—1956 | 三大改造 |
| 社会主义初步探索 | 1956—1978 | |

## 二、重大事件

### 旧民主主义革命时期（1840—1919）

| 事件 | 时间 | 核心意义/考点 |
|------|------|---------------|
| **虎门销烟** | 1839 | 林则徐领导；鸦片战争导火索；显示中国人民反侵略决心 |
| **鸦片战争** | 1840 | 中国近代史起点；社会性质逐步沦为半殖民地半封建社会；签订《南京条约》《虎门条约》（中英）、《望厦条约》（中美）、《黄埔条约》（中法） |
| **三元里抗英** | 1841 | 近代中国人民第一次大规模反侵略斗争；显示人民力量 |
| **太平天国运动** | 1851—1864 | 农民战争最高峰；纲领《天朝田亩制度》（以解决土地问题为中心，否定封建土地剥削但未废除）和《资政新篇》（具有资本主义色彩）；失败根本原因是农民阶级局限性 |
| **洋务运动** | 1860s—1895 | 封建地主阶级自救运动；口号"自强、求富"；兴办军用企业和民用企业（官督商办为资本主义性质）；创办新式学堂、派遣留学生；失败标志：甲午战争北洋海军全军覆没；失败根本原因：只学技术不学制度 |
| **甲午中日战争** | 1894—1895 | 《马关条约》签订，大大加深半殖民地半封建化程度；刺激列强瓜分中国野心；民族意识普遍觉醒 |
| **戊戌维新** | 1898 | 资产阶级维新派首次登上历史舞台；自上而下改良道路；托古改制（未否定传统文化）；失败根本原因：资产阶级自身局限性；说明资产阶级改良道路行不通 |
| **义和团运动** | 1900 | 反帝爱国运动；在粉碎列强瓜分中国斗争中发挥重大作用；《辛丑条约》签订，中国完全沦为半殖民地半封建社会 |
| **清末新政** | 1901—1911 | 正式废除科举；预备仿行宪政激化了社会矛盾 |
| **中国同盟会** | 1905·东京 | 第一个全国性资产阶级革命政党；纲领：驱除鞑虏、恢复中华、创立民国、平均地权 |
| **萍浏醴起义** | 1906·湘赣边界 | 近代革命派第一次武装起义；同盟会成立后首次起义；扩大革命影响 |
| **黄花岗起义** | 1911·广州 | 同期影响最大的武装起义；七十二烈士葬于黄花岗；鼓舞革命党人斗志 |
| **保路运动** | 1911·四川 | 反对清政府出卖铁路权；为武昌起义创造条件 |
| **辛亥革命** | 1911 | 推翻清王朝，结束两千多年封建君主专制制度；建立中华民国（资产阶级共和国性质）；民主共和观念深入人心；旧民主主义革命高峰；失败根本原因：资本主义建国方案在中国行不通 |
| **中华民国成立** | 1912.1.1 | 亚洲第一个共和国；孙中山任临时大总统；颁布《临时约法》 |
| **护国运动** | 1915—1916 | 反对袁世凯复辟帝制；蔡锷等领导；维护共和制度 |
| **五四运动** | 1919 | 新民主主义革命开端；工人阶级登上历史舞台；促进马克思主义广泛传播；民族意识全面觉醒；直接导火索：巴黎和会中国外交失败 |

### 新民主主义革命时期（1919—1949）

| 事件 | 时间 | 核心意义/考点 |
|------|------|---------------|
| **中国共产党成立** | 1921 | 中国革命面貌焕然一新；一大确立党的名称，决定首先集中力量组织工人 |
| **中共二大** | 1922 | 第一次提出彻底的反帝反封建民主革命纲领；提出统一战线思想；采取群众路线方法 |
| **中共三大** | 1923 | 决定共产党员以个人身份加入国民党，建立革命统一战线 |
| **国民党一大** | 1924·广州 | 第一次国共合作正式形成；新三民主义成为合作政治基础；国民革命开始 |
| **五卅运动** | 1925·上海 | 大革命高潮的起点；掀起全国反帝爱国运动；省港大罢工持续16个月 |
| **第一次国共合作/大革命** | 1924—1927 | 党内合作方式；政治基础：新三民主义；高潮标志：五卅运动；失败根本原因：不善于将马列主义与中国实际相结合；经验教训推动马克思主义中国化探索 |
| **四一二政变** | 1927·上海 | 蒋介石发动反革命政变；大革命局部失败；国共合作开始破裂 |
| **七一五政变** | 1927·武汉 | 汪精卫发动反革命政变；大革命完全失败；国共合作彻底破裂 |
| **南昌起义** | 1927.8.1 | 武装反抗国民党反动派的第一枪；中国共产党创建人民军队的开端；党指挥枪的开端 |
| **八七会议** | 1927.8.7 | 从大革命到土地革命的转折；确定土地革命和武装反抗国民党反动派总方针；"枪杆子里出政权" |
| **秋收起义** | 1927.9 | 打出"工农革命军"旗帜；秋收起义后转向农村 |
| **三湾改编** | 1927·江西 | 建设新型人民军队的开端；"支部建在连上"；确立党对军队的绝对领导 |
| **广州起义** | 1927.12 | 中国共产党领导的武装反抗国民党反动派的又一次重要起义 |
| **井冈山革命根据地** | 1927后 | 第一个红色政权：茶陵县工农兵政府；提出工农武装割据思想，农村包围城市道路理论雏形 |
| **井冈山会师** | 1928 | 朱德、陈毅与毛泽东会师；成立中国工农红军第四军；巩固井冈山革命根据地 |
| **九一八事变** | 1931·沈阳 | 中国局部抗战开始；揭开世界反法西斯战争序幕；东北三省沦陷 |
| **红军长征** | 1934—1936 | 战略大转移；实现了中国共产党和中国革命事业从挫折走向胜利的伟大转折 |
| **遵义会议** | 1935.1 | 生死攸关的转折点；解决军事和组织问题；确立毛泽东在党中央和红军的领导地位；党开始走向成熟 |
| **一二·九运动** | 1935·北平 | 抗日救亡运动新高潮；促进中华民族觉醒；为抗日民族统一战线准备条件 |
| **瓦窑堡会议** | 1935.12 | 解决政治问题（统一战线）；提出建立抗日民族统一战线 |
| **西安事变** | 1936.12 | 时局转换的枢纽；十年内战结束；抗日民族统一战线初步形成 |
| **七七事变/卢沟桥事变** | 1937.7.7 | 中华民族全面抗战开始；开辟世界反法西斯战争东方主战场 |
| **平型关大捷** | 1937·山西 | 全面抗战以来中国军队主动寻歼敌人的第一次重大胜利；打破"日军不可战胜"神话 |
| **台儿庄战役** | 1938·山东 | 抗战以来国民党正面战场最大胜利；振奋全国军民抗战信心 |
| **百团大战** | 1940·华北 | 敌后战场规模最大战役；彭德怀指挥；振奋全国军民抗战信心 |
| **皖南事变** | 1941·皖南 | 国民党顽固派制造的反共事件；新四军遭受重大损失；第二次反共高潮顶点 |
| **延安整风运动** | 1942·延安 | 反对主观主义、宗派主义、党八股；确立实事求是思想路线；为抗战胜利奠定思想基础 |
| **抗日战争** | 1931—1945 | 近代以来中国抗击外敌入侵第一次完全胜利；中华民族由近代以来陷入深重危机走向伟大复兴的历史转折点；收回台湾及澎湖列岛是完全胜利的标志 |
| **重庆政协/老政协** | 1946·重庆 | 签订五项协议；国民党撕毁协议发动内战；和平建国希望破灭 |
| **解放战争** | 1946—1949 | 推翻国民党反动统治；三大战役奠定胜利基础；1949年4月占领南京标志国民党反动统治覆灭 |
| **挺进大别山** | 1947·大别山 | 揭开战略进攻序幕；刘邓大军千里跃进；直接威胁国民党统治中心 |
| **渡江战役** | 1949·长江 | 解放南京；国民党政权覆灭 |
| **新政协/中国人民政治协商会议** | 1949·北京 | 通过《共同纲领》；代行全国人大职权；标志中共领导多党合作制确立；新民主主义性质 |
| **开国大典/新中国成立** | 1949.10.1 | 中华人民共和国成立；新民主主义革命基本胜利；结束封建专制；国情变为新民主主义社会 |

### 社会主义革命和建设时期

| 事件 | 时间 | 核心意义/考点 |
|------|------|---------------|
| **土地改革完成** | 1952 | 完成民主革命遗留任务；新民主主义社会阶段（1949—1953）结束标志 |
| **抗美援朝** | 1950—1953 | 保家卫国；提高中国国际地位；巩固新生政权；打破美军不可战胜神话 |
| **镇反运动** | 1950—1953 | 镇压反革命分子；巩固新生政权；稳定社会秩序 |
| **三大改造完成** | 1956 | 社会主义基本制度确立；中国进入社会主义社会（最主要标志） |
| **中共八大** | 1956 | 社会主义改造完成后，正确分析社会主要矛盾和主要任务 |
| **《论十大关系》** | 1956 | 探索中国社会主义建设道路的开端；提出马克思主义与中国实际"第二次结合" |
| **反右运动** | 1957 | 反右派斗争扩大化；一批知识分子被错划为右派；社会主义建设遭到挫折 |
| **大跃进** | 1958 | 急于求成的左倾错误；违背经济发展规律；造成国民经济严重困难 |
| **人民公社化** | 1958 | "一大二公"；平均主义严重；挫伤农民生产积极性 |

### 改革开放和社会主义现代化建设新时期

| 事件 | 时间 | 核心意义/考点 |
|------|------|---------------|
| **真理标准大讨论** | 1978 | 为重新确立实事求是的思想路线作思想理论准备 |
| **十一届三中全会** | 1978.12 | 改革开放开端；把党和国家工作重心转移到经济建设上来；重新确立实事求是思想路线 |
| **南方谈话** | 1992·深圳 | 社会主义本质论；市场经济不等于资本主义；推动改革开放进入新阶段 |
| **中共十四大** | 1992·北京 | 建立社会主义市场经济体制；改革开放进入新阶段 |
| **中共十五大** | 1997·北京 | 邓小平理论确立为党的指导思想；依法治国基本方略 |
| **香港回归** | 1997.7.1 | "一国两制"成功实践；洗雪百年国耻；祖国统一大业迈出重要一步 |
| **澳门回归** | 1999.12.20 | "一国两制"成功实践；洗雪百年国耻；祖国统一大业迈出重要一步 |

## 三、中共重要会议

| 会议 | 时间地点 | 核心考点 |
|------|----------|----------|
| **中共一大** | 1921·上海 | 中国共产党成立；中国革命面貌焕然一新；确立党的名称；决定首先集中力量组织工人 |
| **中共二大** | 1922·上海 | 第一次提出彻底的反帝反封建民主革命纲领（最高+最低纲领）；提出统一战线思想；采取群众路线方法 |
| **中共三大** | 1923·广州 | 决定共产党员以个人身份加入国民党，建立革命统一战线；第一次国共合作（党内合作） |
| **中共四大** | 1925·上海 | 提出无产阶级在民主革命中的领导权问题；提出工农联盟问题 |
| **八七会议** | 1927·汉口 | 纠正陈独秀右倾机会主义错误；确定土地革命和武装反抗国民党反动派总方针；"枪杆子里出政权"；从大革命到土地革命的转折 |
| **古田会议** | 1929·福建 | 新型人民军队正式定型；思想建党、政治建军；确立党对军队绝对领导（党指挥枪） |
| **遵义会议** | 1935·贵州 | 生死攸关的转折点；解决军事和组织问题；确立毛泽东在党中央和红军的领导地位；党开始走向成熟 |
| **瓦窑堡会议** | 1935·陕北 | 解决政治问题；建立抗日民族统一战线 |
| **洛川会议** | 1937·陕北 | 制定全面抗战路线（人民战争路线）；通过《抗日救国十大纲领》 |
| **六届六中全会** | 1938·延安 | 首次提出"马克思主义中国化"命题（《论新阶段》） |
| **中共七大** | 1945·延安 | 把毛泽东思想确立为党的指导思想并写入党章；党走向了成熟 |
| **七届二中全会** | 1949·西柏坡 | 工作重心由乡村转向城市；提出"两个务必"；提出由农业国变为工业国、由新民主主义社会变为社会主义社会 |
| **七届三中全会** | 1950 | 中心任务：三年左右争取财政经济状况基本好转；方针：不要四面出击 |
| **中共八大** | 1956·北京 | 社会主义改造完成后，正确分析社会主要矛盾和主要任务 |
| **十一届三中全会** | 1978·北京 | 改革开放开端；工作重心转移到经济建设；重新确立实事求是思想路线 |

## 四、重要文献

| 文献 | 作者/时期 | 核心考点 |
|------|----------|----------|
| **《天朝田亩制度》** | 太平天国 | 最能体现太平天国社会理想；以解决土地问题为中心；提出"凡天下田，天下人同耕"；否定封建土地剥削但未付诸实施 |
| **《资政新篇》** | 洪仁玕 | 中国近代第一个具有资本主义色彩的方案；但未付诸实施 |
| **《新学伪经考》《孔子改制考》** | 康有为 | 托古改制；借孔子推行改革；未否定传统文化 |
| **《革命军》** | 邹容 | 宣传资产阶级民主革命思想 |
| **《我的马克思主义观》** | 李大钊 | 系统介绍马克思主义 |
| **《中国社会各阶级的分析》** | 毛泽东 1925 | 指出中国革命的首要问题：分清敌友 |
| **《湖南农民运动考察报告》** | 毛泽东 1927 | 指出农民问题是国民革命的中心问题；肯定农民在革命中的伟大作用 |
| **《中国的红色政权为什么能够存在？》《井冈山的斗争》** | 毛泽东 1928 | 提出工农武装割据思想；农村包围城市道路理论雏形 |
| **《星星之火，可以燎原》** | 毛泽东 1930 | 标志着革命新道路理论初步形成；毛泽东思想初步形成标志 |
| **《反对本本主义》** | 毛泽东 1930 | 提出思想路线问题（"没有调查，没有发言权"） |
| **《论反对日本帝国主义的策略》** | 毛泽东 1935 | 解决政治问题（统一战线） |
| **《实践论》《矛盾论》** | 毛泽东 1937 | 系统、科学阐明思想路线问题 |
| **《论持久战》** | 毛泽东 1938 | 抗日战争是持久战；最后胜利属于中国；党领导抗战的纲领性文件 |
| **《新民主主义论》** | 毛泽东 1940 | 系统阐述新民主主义革命理论；毛泽东思想达到成熟 |
| **《论联合政府》** | 毛泽东 1945 | 提出建立民主联合政府的主张 |
| **《论人民民主专政》** | 毛泽东 1949 | 阐述新中国政权性质：人民民主专政 |
| **《论十大关系》** | 毛泽东 1956 | 探索中国社会主义建设道路的开端；"第二次结合" |
| **《关于正确处理人民内部矛盾的问题》** | 毛泽东 1957 | 区分两类不同性质矛盾 |

## 五、土地政策演变（徐涛重点）

| 时期 | 政策 | 特点 |
|------|------|------|
| 太平天国 | 《天朝田亩制度》 | 提出"凡天下田，天下人同耕"；否定封建土地剥削；未付诸实施 |
| 辛亥革命 | 旧三民主义民生主义 | 平均地权；未将土地分给农民 |
| 大革命时期 | 新三民主义民生主义 | 平均地权、节制资本；后提出"耕者有其田" |
| 土地革命时期 | 《兴国土地法》 | 消灭封建地主土地私有制，实行农民土地私有制；中国历史上第一个可付诸实施的比较完整的土地革命纲领 |
| 抗日战争时期 | 减租减息 | 削弱封建土地剥削；没有否定封建土地剥削；没有"耕者有其田" |
| 解放战争时期 | "五四指示" | 体现"耕者有其田"；否定并废除封建土地剥削（在解放区） |
| 建国后土改 | 《中华人民共和国土地改革法》 | 体现"耕者有其田"；否定并废除封建土地剥削；范围更大；保存富农经济 |

### 对待富农政策变化
| 时期 | 政策 |
|------|------|
| 土地革命时期 | 限制富农 |
| 抗日战争时期 | 允许收租 |
| 解放战争时期 | 一般不变动富农财产；征收富农多余土地 |
| 建国后土改 | 保存富农经济 |

## 六、易混淆对比

### 1. 旧民主主义革命 vs 新民主主义革命

| 对比项 | 旧民主主义革命 | 新民主主义革命 |
|--------|---------------|---------------|
| 分界线 | 五四运动 | 五四运动 |
| 领导者 | 资产阶级 | 无产阶级（通过共产党） |
| 性质 | 资产阶级民主革命 | 资产阶级民主革命 |
| 任务 | 反帝反封建 | 反帝反封建 |
| 指导思想 | 资产阶级民主思想 | 马克思主义 |
| 前途 | 资本主义 | 社会主义 |

**关键**：决定革命性质的是**任务和对象**，不是领导者。

### 2. 三个"开端/转折"

| 事件 | 定位 |
|------|------|
| **五四运动** | 新民主主义革命开端 |
| **南昌起义** | 创建人民军队的开端；党指挥枪的开端 |
| **三湾改编** | 建设新型人民军队的开端 |
| **八七会议** | 从大革命到土地革命的转折 |
| **西安事变** | 从土地革命到全面抗战的转折（时局转换枢纽） |
| **遵义会议** | 生死攸关的转折点；党开始走向成熟 |
| **红军长征胜利** | 党和中国革命事业从挫折走向胜利的伟大转折 |
| **抗日战争胜利** | 中华民族由深重危机走向伟大复兴的历史转折点 |
| **人民解放军转入战略进攻** | 中国革命的历史转折点 |
| **护法运动失败** | 旧民主主义革命终结的标志 |
