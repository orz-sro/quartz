# 唯物辩证法 - 量变质变规律与否定之否定规律

## 考点19 量变质变规律（第二规律）

### 基本概念

| 概念 | 含义 |
|------|------|
| **质** | "是什么"的问题 |
| **量** | 使认识深化和精确化，正确估计事物在实践中的地位和作用 |
| **度** | 一个区间 |
| **关节点** | 两个端点、临界值，超过则此物转化为他物 |
| **量变** | 变化不显著 |
| **质变** | 事物性质发生根本变化 |

### 量变与质变的辩证关系

**对立统一关系**——既联系，又统一

| 关系 | 内容 |
|------|------|
| **区别** | 量变是不显著变化，质变是事物性质发生根本变化 |
| **量变体现** | 事物发展的连续性 |
| **质变体现** | 事物发展连续性的中断 |
| **联系** | 量变之中有质变，质变之中有量变 |

**关键理解**：质变从长期来看，不是一个静态的过程，只是漫长的量变过程中的一个点

### 方法论

> 既要注重**量的积累**，又要注重**质的突破**

## 考点20 否定之否定规律（第三规律）

### 基本概念

| 概念 | 含义 |
|------|------|
| **肯定因素** | 维持事物得以存在 |
| **否定因素** | 促使现存事物灭亡 |

### 辩证否定观

| 观点 | 内容 |
|------|------|
| **辩证否定观** | 否定是**自我否定**，而不是外在力量否定，坚持**扬弃** |
| **形而上学否定观** | 否定是外在力量消灭事物，主张肯定一切或否定一切 |

### 否定之否定规律

```
A（原本状态）
    ↓ 第一次否定
B（对立面）
    ↓ 第二次否定
A'（更高阶段的A）
```

**两次否定，三个状态**：A → B → A'

**马克思的观点**：既看到前进上升，也看到波浪螺旋

### 错误观点

| 错误 | 表现 |
|------|------|
| **循环论** | 只看螺旋不看上升 |
| **直线论** | 只看前进不看波浪螺旋 |

### 方法论

> 不要奢望事情一帆风顺，要经得起困难和挫折，坚定信心，知难而上，**大方向始终是向前发展的**

## 徐涛点拨


- **易错点**：  - 量变是不显著变化，质变是事物性质发生根本变化
  - 量变体现事物发展的**连续性**，质变体现**连续性的中断**
  - 质变从长期来看，只是漫长的量变过程中的一个点

- **易错点**：  - 辩证否定观：否定是**自我否定**，坚持**扬弃**
  - 形而上学否定观：否定是外在力量消灭事物，主张肯定一切或否定一切

- **易错点**：  - 循环论：只看螺旋不看上升
  - 直线论：只看前进不看波浪螺旋
  - 大方向始终是向前发展的

## 真题角度

- 从**量变质变**角度考查：度、关节点、量变质变的关系
- 从**辩证否定观**角度考查：自我否定、扬弃
- 从**否定之否定规律**角度考查：两次否定三个状态、错误观点

## 核心考点速记

- **量变质变**：量变是不显著变化，质变是根本变化
- **度**：一个区间；**关节点**：临界值
- **方法论**：量的积累 + 质的突破
- **辩证否定**：自我否定，扬弃
- **否定之否定**：A → B → A'，两次否定三个状态
- **错误观点**：循环论（只看螺旋）、直线论（只看前进）
