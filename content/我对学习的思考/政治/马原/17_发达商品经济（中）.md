# 马克思主义政治经济学 - 发达商品经济（中）

## 考点68 资本积累

### 概念

> **资本积累**：把剩余价值转化为资本（资本家用昨天在工人身上榨取的剩余价值来加大今天对工人的剥削）

### 两个源泉

| 概念 | 源泉 |
|------|------|
| **扩大再生产** | 源泉是资本积累 |
| **资本积累** | 源泉是剩余价值 |

### 资本积累规模的大小取决于（成正比）

- 对工人的剥削程度
- 劳动生产率的高低
- 所用资本和所费资本之间的差额
- 资本家预付资本大小

### 资本积累的后果

- 社会财富占有**两极分化**
- 资本主义社会**失业现象**

### 资本有机构成

| 构成 | 内容 |
|------|------|
| **资本技术构成** | 生产资料与劳动力的比例（物∶人） |
| **资本价值构成** | 不变资本与可变资本的比例（钱∶钱） |

**口诀**：
- 技术变，价值变，有机就变
- 技术不变，价值变，有机不变

### 资本积累的逻辑链条

```
资本积累 → 资本有机构成提高 → 失业 → 社会两极分化 → 资本主义灭亡
```

## 考点69 资本的循环周转与再生产

### 资本循环的三个阶段

| 阶段 | 资本形态 |
|------|---------|
| **采购阶段** | 货币资本 |
| **生产阶段** | 生产资本 |
| **售卖阶段** | 商品资本 |

**资本循环**：通过售卖收回资本并赚到钱，资本回归货币形态

**资本周转**：多次反复的循环

### 资本周转与剩余价值

> 资本周转越快，在一定时期内带来的剩余价值就越多

- 资本周转速度与周转时间**成反比**

### 固定资本和流动资本

| 类型 | 价值转移方式 |
|------|-------------|
| **固定资本** | 价值在生产过程中**分多次**转移到商品中 |
| **流动资本** | 价值在生产过程中**一次性**转移到商品中 |

### 资本的三次划分

| 划分方式 | 类型 |
|---------|------|
| 按在剩余价值生产中的作用 | 不变资本（c）和可变资本（v） |
| 按价值周转方式 | 固定资本和流动资本 |
| 按资本循环阶段 | 货币资本、生产资本、商品资本 |

### 社会再生产

- **第Ⅰ部类**：生产生活资料的部门
- **第Ⅱ部类**：生产生产资料的部门

**商品价值构成**：c + v + m

## 徐涛点拨


- **易错点**：  - 扩大再生产的源泉是**资本积累**
  - 资本积累的源泉是**剩余价值**

- **易错点**：  - 技术变，价值变，有机就变
  - 技术不变，价值变，有机不变


- **易错点**：  - 资本周转越快，在一定时期内带来的剩余价值就越多
  - 资本周转速度与周转时间**成反比**

- **资本积累源泉**：剩余价值
