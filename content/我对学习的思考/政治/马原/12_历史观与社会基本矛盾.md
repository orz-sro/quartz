# 唯物史观 - 历史观基本问题与社会基本矛盾

## 考点44 唯物史观和唯心史观的对立

### 社会存在和社会意识

- 概念就是人类社会历史领域的**物质和意识**
- 可按照哲学中"物质和意识的关系问题"的逻辑理解

### 唯心史观的缺陷

- 没有看到**物质力量、经济力量**的决定性作用
- 没有看到**人民群众**的决定性作用

---

## 考点45 社会存在和社会意识及其辩证关系

### 社会存在的构成

| 因素 | 地位 |
|------|------|
| **人口因素** | 重要影响因素 |
| **自然地理环境** | 重要影响因素 |
| **物质生产方式** | **决定性因素** |

### 生产方式

> 生产方式 = 生产力 + 生产关系

其中**生产力**更具决定性作用

### 社会意识的构成

| 类型 | 特点 |
|------|------|
| **社会心理** | 浅层次、不系统、感性认识为主 |
| **社会意识形式** | 深层次、系统化、理性认识为主 |

### 社会意识形式的分类

| 类型 | 含义 | 例子 |
|------|------|------|
| **意识形态** | 和阶级或社会集团利益有关 | 政治法律思想、道德、哲学、艺术 |
| **非意识形态** | 不反映特定社会集团的利益和要求 | 自然科学、语言学、数学 |

### 社会存在与社会意识的辩证关系

- 社会存在决定社会意识
- 社会意识会随着社会存在的发展而变化（**或迟或早**，不是立刻）

### 社会意识的相对独立性

| 表现 | 说明 |
|------|------|
| **不完全同步性和不平衡性** | 经济先进的国家，思想未必先进；经济落后的国家，思想未必落后 |
| **相互影响且具有历史继承性** | 社会意识内部各种形式之间相互影响 |
| **最突出表现** | 社会意识对社会存在具有**能动的反作用** |

### 唯物史观和唯心史观的区分

| 标准 | 内容 |
|------|------|
| **根本分野** | 主张社会存在决定社会意识，还是社会意识决定社会存在 |
| **分水岭** | 历史创造者问题 |

---

## 考点46 生产力和生产关系矛盾运动的规律（第一对社会基本矛盾）

### 生产力

**基本要素**：
> 生产力 = 劳动资料 + 劳动对象 + 劳动者 = 生产资料 + 劳动者

**现代生产特点**：脑力劳动日益具有决定性意义

### 生产力与科技的关系

| 观点 | 说明 |
|------|------|
| 科技属于生产力 | 但不是生产力中独立的要素 |
| 科技渗透在生产力三要素中 | - |
| 科技在生产劳动中起决定性作用 | 但在社会历史发展中只起**重要作用** |

### 生产关系

| 判断标准 | 内容 |
|---------|------|
| 判定社会经济时代的客观依据 | **生产工具** |
| 判定社会经济结构性质的客观依据 | **生产资料所有制关系** |

### 生产力与生产关系的辩证关系

- 生产力 + 生产关系 = 生产方式
- 当生产关系不适应新的生产力（束缚了生产力发展），社会将发生革命、改革

### 人类社会发展第一规律

> 生产力与生产关系的矛盾运动及其规律

---

## 考点47 经济基础和上层建筑矛盾运动的规律（第二对社会基本矛盾）

### 经济基础

- 生产力决定生产关系
- 经济基础本质上是生产关系
- 所以生产力决定经济基础

### 上层建筑

| 类型 | 内容 |
|------|------|
| **观念上层建筑** | = 意识形态 |
| **政治上层建筑** | = 制度、组织、设施 |

**不属于上层建筑的社会意识**：非意识形态、社会心理

### 上层建筑的核心

| 类型 | 核心 |
|------|------|
| 观念上层建筑 | **政治法律思想** |
| 政治上层建筑 | **国家政权** |

### 两种"是否先进"的判断标准

| 判断对象 | 标准 |
|---------|------|
| **生产关系是否先进** | 是否适应生产力的发展 |
| **上层建筑是否先进** | 它所服务的经济基础是否适应生产力的发展 |

### 人类社会发展第二规律

> 上层建筑一定要适合经济基础状况的规律

---

## 考点48 人类普遍交往与世界历史的形成发展

- 资本主义出现之前：人类历史是相对孤立的地区史
- 资本主义出现之后：人类历史成为世界史

## 徐涛点拨


- **易错点**：  - 人口因素和自然地理环境是**重要影响因素**
  - 物质生产方式是**决定性因素**
  - 生产方式 = 生产力 + 生产关系，其中**生产力**更具决定性作用

- **易错点**：  - 意识形态：和阶级或社会集团利益有关（政治法律思想、道德、哲学、艺术）
  - 非意识形态：不反映特定社会集团的利益和要求（自然科学、语言学、数学）

- **易错点**：  - 经济先进的国家，思想未必先进
  - 经济落后的国家，思想未必落后

- **易错点**：  - 科技属于生产力，但不是生产力中独立的要素
  - 科技在生产劳动中起**决定性作用**，但在社会历史发展中只起**重要作用**




---

## 真题角度

- 从**社会存在**角度考查：决定性因素是物质生产方式

- 从**社会意识**角度考查：相对独立性、最突出表现

- 从**生产力与科技**角度考查：科技不是独立要素

- 从**社会基本矛盾**角度考查：第一规律、第二规律

---

## 核心考点速记

- **社会存在决定因素**：物质生产方式
- **生产力要素**：劳动资料+劳动对象+劳动者
- **科技**：渗透在生产力三要素中，不是独立要素
- **判定经济时代**：生产工具
- **判定经济结构性质**：生产资料所有制关系
- **第一规律**：生产力与生产关系的矛盾运动
- **第二规律**：上层建筑要适合经济基础状况
