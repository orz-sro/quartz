# 马克思主义认识论 - 真理与价值

## 考点37 真理及其特性

### 真理的客观性

- 真理的**内容**、**检验标准**是客观的
- 真理的**形式**是主观的
- 从总体来看，真理是**客观的**

### 易混淆说法

| 说法 | 正误 |
|------|------|
| 真理是客观的 | √ |
| 真理是主观的 | × |
| 真理有主观的一面 | √ |

### 错误的真理观

| 观点 | 错误 |
|------|------|
| 马赫主义、实用主义 | "有用即真理"（×） |

**正确说法**：真理一定是有用的（√）

### 真理的一元性

- 真理的**客观性**决定了真理的**一元性**
- 二者具有内在的一致性（考试中如果选项同时出现，同选同不选）

### 真理的绝对性和相对性

| 概念 | 含义 |
|------|------|
| **绝对真理** | 真理中正确的部分（颗粒） |
| **相对真理** | 今天的一个真理，明天可能被修正 |

**关系**：
- 任何真理的相对性之中都包含着真理绝对性的颗粒
- 无数相对真理的总和构成了绝对真理

### 为什么真理既有绝对性又有相对性

根源于人的认识能力既有**至上性**又有**非至上性**

| 特性 | 含义 | 对应真理特性 |
|------|------|-------------|
| **至上性** | 人的认识能力完全有能力认知这个世界 | 绝对性 |
| **非至上性** | 目前的认知能力还没有那么强 | 相对性 |

### 两种错误观点

| 错误 | 表现 |
|------|------|
| **教条主义、思想僵化** | 夸大真理的绝对性，否认真理的相对性 |
| **怀疑主义、诡辩论** | 夸大真理的相对性，否认真理的绝对性 |

### 能否转化看范围

| 说法 | 正误 |
|------|------|
| 真理和谬误在一定范围内的对立是绝对的，不能相互转化 | √ |
| 在同一范围内，真理和谬误可以相互转化 | × |

---

## 考点39 真理的检验标准

### 为什么实践是检验真理的唯一标准

- **真理的本性**：主观符合客观
- **实践的特点**：实践具有直接现实性（客观实在性）

**逻辑证明不能作为检验真理的标准**：
- 逻辑是从实践中来的
- 逻辑证明依赖于前提假设

## 考点40 真理与价值的辩证统一

### 价值的特性

| 特性 | 含义 |
|------|------|
| **主体性** | 主体不同，价值就不同（≠主观性） |
| **客观性** | 不以人的意志为转移 |
| **多维性** | 主体的价值关系具有多样性 |
| **社会历史性** | 不同的历史阶段，价值不同 |

**注意**：主体性≠主观性。价值会因人而异，但不会因人的想法而异

### 价值评价

| 类型 | 认识对象 |
|------|---------|
| **知识性认识** | 客体本身 |
| **价值评价性认识** | 主客体之间的价值关系 |

### 两种尺度

| 尺度 | 含义 |
|------|------|
| **真理尺度** | 规律（该怎么做） |
| **价值尺度** | 能动（想怎么做） |

## 考点43 从必然走向自由

### 基本概念

| 概念 | 含义 |
|------|------|
| **必然** | = 规律 |
| **自由** | = 能动 |

### 自由与规律的关系

- 自由**不是**摆脱规律的束缚和制约
- 自由是**对规律的认识和利用**
- 要以必然为前提，争取自由

### 错误观点

| 错误 | 表现 |
|------|------|
| **唯意志论** | 夸大自由否定必然 |
| **宿命论** | 夸大必然否定自由 |

## 徐涛点拨


- **易错点**：  - 真理是客观的（√）
  - 真理是主观的（×）
  - 真理有主观的一面（√）

- **易错点**：  - "有用即真理"（×）
  - "真理一定是有用的"（√）

- **易错点**：  - 根源于人的认识能力既有至上性又有非至上性
  - 教条主义夸大绝对性，怀疑主义夸大相对性

- **易错点**：在同一范围内，真理和谬误**不能**相互转化

- **易错点**：逻辑证明不能作为检验真理的标准

- **易错点**：价值会因人而异，但不会因人的想法而异

- **易错点**：  - 唯意志论：夸大自由否定必然
  - 宿命论：夸大必然否定自由

## 真题角度

- 从**真理的客观性**角度考查：真理是客观的、有用即真理的错误
- 从**真理的绝对性和相对性**角度考查：两种错误观点
- 从**检验真理的标准**角度考查：实践是唯一标准
- 从**自由与必然**角度考查：自由是对规律的认识和利用

---

## 核心考点速记

- **真理特性**：客观性、一元性、绝对性、相对性
- **检验真理唯一标准**：实践
- **价值特性**：主体性、客观性、多维性、社会历史性
- **真理与价值**：真理尺度（规律）+ 价值尺度（能动）
- **自由与必然**：自由是对规律的认识和利用
