# 新民主主义革命理论（下）

## 考点12 新民主主义革命的道路

### 道路理论的形成

| 阶段 | 标志 |
|------|------|
| **初步形成** | 《中国的红色政权为什么能够存在？》《井冈山的斗争》《星星之火，可以燎原》 |
| **正式确立** | 六届六中全会《战争与战略问题》 |

**重要结论**：道路理论初步形成标志着**毛泽东思想初步形成**

### 六届六中全会的两个考点

| 文章 | 意义 |
|------|------|
| 《论新阶段》 | 第一次明确提出"马克思主义的中国化"命题 |
| 《战争与战略问题》 | 确立了新民主主义的革命道路 |

### 道路的内容

> "农村包围城市、武装夺取政权"

**注意**：这是两个半句，做题时要看清是问整体还是分开问

### 三个关键词的对应

- 土地革命
- 武装斗争
- 农村革命根据地

## 考点13 新民主主义革命的三大法宝

### 三大法宝 = 新民主主义革命的总经验

| 法宝 | 特点 |
|------|------|
| **统一战线** | 理论性最强、考点最多 |
| **武装斗争** | - |
| **党的建设** | - |

### 统一战线

#### 必要性（为什么要建立）

> 半殖民地半封建社会的阶级状况决定的（**两头小、中间大**）

| 阶级 | 位置 |
|------|------|
| 无产阶级、大地主大资产阶级 | 两头（小） |
| 农民、小资、民资等 | 中间（大） |

#### 可能性

> 诸多矛盾交织一起

#### 两个联盟

| 联盟 | 内容 | 地位 |
|------|------|------|
| **与劳动者的联盟** | 工农联盟 | 主要联盟 |
| **与非劳动者的联盟** | 与民族资产阶级等的联盟 | - |
