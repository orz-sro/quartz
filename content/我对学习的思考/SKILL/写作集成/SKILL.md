# 写作集成：考研英语写作练习批改

把用户写的练习句子对照参考答案逐句批改，产出格式统一、可直接复习的 Obsidian 笔记。核心不只是给答案，而是带用户通过<font color="#79c0ff">词性</font>和<font color="#79c0ff">句子结构</font>理解错在哪。

## 文件位置与结构

- vault 根目录：`D:\Desktop\数一\我对学习的思考`
- 写作训练目录：`英语\写作\每周训练\`
- 每周文件命名：
  - `第N周：练习.md` —— 题目 + 用户答案 + 批改（主文件，批改写这里）
  - `第N周：练习_答案.md` —— 参考答案（批改时对照，不直接展示给用户抄）
  - `第N周：主题.md` —— 本周句型讲解（如「第二周：There be 句型」）
- 主笔记：`英语\写作\写作.md`

## 批改流程

1. 先读 `第N周：练习.md`（用户答案）和 `第N周：练习_答案.md`（参考答案）。
2. 逐句对照，找出：拼写、主谓一致、词性、搭配、单复数/所有格、句子结构（run-on / 缺成分 / with 复合结构误用）等错误。
3. 按下方「批改格式」填入每个练习的 `正确写法` 和 `批改反馈`，替换占位符 `（答案已隐藏…）` 和 `（写完后我来补充）`。
4. 用户在答案里用括号写的困惑（如「(感觉有点奇怪的搭配)」「(忘记其他表示足够的单词)」），必须单独用 `> [!hint] 关于……` 回应。
5. 全部批改完后，在「使用建议」前加一个 `## 本周高频错误复盘` 小节，归纳本周反复出现的错误类型。

## 批改格式（严格遵守）

每个练习按这个结构填写：

```markdown
**正确写法**

```text
（参考答案，完整句子）
```

> [!danger] 批改反馈
> - ❌ `错误片段` → <font color="#7ee787">`正确写法`</font>（简短说明错因）
> - ⚠️ `可改进处` → <font color="#7ee787">`更优表达`</font>（说明为什么更好）
> - ✅ 结构正确的部分要点名表扬

> [!hint] 为什么 / 关于你的困惑
> 解释语法或搭配原因，带出词性判断。
```

标记约定：`❌` 硬错误（语法/拼写/搭配错），`⚠️` 可优化（不算错但不够好），`✅` 做对的地方。

## 颜色规范（来自 vault AGENTS.md，深色主题友好）

只用 `<font color="...">` 改字色，<font color="#ff7b72">不用 `<mark>` 高亮</font>：

- `#79c0ff` 浅蓝：语法术语、结构名（如「with 复合结构」「非谓语」「定语从句」）
- `#7ee787` 浅绿：正确写法、可替换表达
- `#ffa657` 浅橙：重点提示、优化建议
- `#ff7b72` 浅红：错误、禁止项

## 词性判断是核心（每次必带）

讲任何错误都要落到<font color="#79c0ff">词性</font>上，引导用户用词性理解句子。四种判断方法：

1. **语法位置**：定语从句缺谓语 → 那个词是动词；`of` 后面 → 需要名词/动名词。
2. **词形**：`-ed` 前无 be 动词 → 非谓语作后置定语；形容词不能直接修饰动词。
3. **固定词性**：`culture`（名词）不能修饰 `communication`，要变 `cultural`（形容词）。
4. **搭配词性**：`convince` 是动词需带宾语（convince sb that），不能 `convincing that`。

高频词性/易混词考点：`search`(搜索) vs `research`(研究)、`technique`(技巧) vs `technology`(科技)、`infect`(传染) vs `affect`(影响)、`profit`(利润) vs `benefit`(好处)、`extend`(延伸) vs `expand`(扩大)、`occupation`(职业) vs `occupying`(占用)。

## 高频错误清单（批改时优先扫这些）

1. **with 复合结构加谓语**：`With so many parents are...` ❌ → `With so many parents knowing...` ✅（with + 名词 + 非谓语，绝不能再有 are/is）。
2. **主谓一致**：被 `of` 短语干扰，如 `the use of products have` ❌ → `has` ✅（核心词 use 是单数）。
3. **词性误用**：名词直接修饰名词，如 `culture communication` ❌ → `cultural communication` ✅。
4. **there be 后多余谓语**：`there are bright spots indicate` ❌ → `bright spots that suggest` ✅（用定语从句）。
5. **run-on 流水句**：两个完整句子无连词拼接 → 改用非限制性定语从句 `, which...`。
6. **所有格**：`people's`（不是 peoples'）、`students'`（不是 students）、`child's`（不是 childs'）。
7. **单复数**：`more and more foreigners`、`full of obstacles`、可数名词单数不能裸用。
8. **固定短语**：`each other` 永不加 s；`be bound to do` 不加 be；`the race to do`（不是 of doing）。

## 本周高频错误复盘模板

批改完在「使用建议」前插入：

```markdown
## 本周高频错误复盘

> [!danger] 这N类错误本周反复出现，下周重点盯
> （用 align 块列出错误类型 + 红绿对照示例）

> [!hint] 自查口诀
> 写完一句按顺序过：谓语单复数 → 有无多余谓语（with/there be 后）→ 修饰语词性 → 名词单复数和所有格 → 拼写。
```

## 注意事项

- <font color="#ff7b72">只改 `第N周：练习.md` 这一个文件</font>，不要动用户写过的其他笔记，也不要重写参考答案文件。
- 用户答案原样保留在 `**你的答案**` 代码块里，不要修改用户的原始作答。
- 填空式占位符（`（答案已隐藏…）`/`（写完后我来补充）`）用 Edit 逐个替换；占位符全文重复，Edit 时务必带上用户答案那行做上下文以保证唯一匹配。
- 用户编辑频繁，Edit 前若报「file modified」先重新 Read。
- 回复用中文，简洁直接。

## 验证

批改完后用 Grep 搜 `写完后我来补充|答案已隐藏` 确认无残留占位符；通读一遍确认每个练习都有 `正确写法` + `批改反馈`，且用户的括号困惑都被回应。
