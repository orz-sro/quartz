这道题本质上是一个$\frac{0}{0}$型的极限求解，但是在直接泰勒展开或是洛必达中都不能看出来结果；
==**主要原因**==  还是分子上的e不能被消除，因此要想到将其因式分解提取出来再利用泰勒或洛必达



>[!title] 重要极限 + 幂指函数变形
> 
>$$
>\Large \lim_{ x \to 0 } \frac{{e^2}}{\left( 1+ \frac{1}{x} \right)^{2x}}
>$$
>
>
>答案： 1，重要极限带入秒了。
>
>---
>
>##  $$\lim_{ x \to 0 } \frac{{e^x}}{\left( 1+ \frac{1}{x} \right)^{x^2}}$$
>答案：$\Large e^ \frac{1}{2}$
>
>#### 解答步骤如下
>
>$$\Large
\begin{aligned}
>& \lim\limits_{ x \to 0 } \frac{e^x}{e^{x^{2}\ln\left( 1+\frac{1}{x} \right)}} \\ \\
>=& e^{ \,\,\lim\limits_{ x \to 0 } x-x^{2}\ln\left( 1+ \frac{1}{x} \right)} \\ \\
>=&e^{ \,\,\lim\limits_{ t \to \infty } \frac{t-\ln(1+t)}{t^2}} \\ \\
>=&e^{ \,\,\lim\limits_{ t \to \infty } \frac{t-t+\frac{t^2}{2}}{t^2}}=e^ \frac{1}{2}
\end{aligned}
>$$

>[!tip] 幂指函数 + 拉中 + 洛必达
>$$
>\large \lim_{ x \to \infty } (x^{\frac{1}{x}}-1)^{\frac{1}{\ln x}}
>$$
>解答如下
>$$
>\begin{gather}
>\Large A=\lim_{ x \to \infty } e^{\frac{\ln\left( e^{\frac{\ln x}{x}}-1 \right)}{\ln x}}\\ \\
>对指数中的函数进行极限求解 \\ \\ 
>不难观察到， {\large e^{\frac{\ln x}{x}}-1}\,\, 可以构造出一个 拉格朗日中值定理 \\  \\
>所以有，\large e^{\frac{\ln x}{x}}-1 =f^\prime(\xi) \left( \frac{\ln x}{x} -0\right) \qquad  \xi =0\\ \\
>带回原式，化简得到 \,\,\,\, \large A = {\Large e^{\frac{\ln(\frac{\ln x}{x})}{\ln x}}} \\ \\
>由洛必达可以得出\,\, \Large A={e^{\frac{1-\ln x}{\ln x}}}=e^{-1}\\ \\ \\
>
> 
>
>
>\end{gather}
>
>$$







>[!warning] 幂指函数 + 拉中 + 泰勒
>$$
>\lim_{ x \to 0}  \frac{{e^{(1+x)^\frac{1}{x}} - (1 + x)^{\frac{e}{x}}}}{x^2}
>$$
>解题步骤：
>$$
>\begin{gather}
>第一眼就知道要抬\,\, e\,\,，
>所以先变化式子 \\ \\
>\large \lim_{ x \to 0 } \frac{e^{(1+x)^\frac{1}{x}} - e^{\frac{e}{x}\ln(1 + x)}}{x^2} \\ \\ 
>直接拉格朗日 \\ \\
>\Large \lim_{ x \to 0 }\,\, e^\xi\,\, \frac{(1+x)^\frac{1}{x}-\frac{e}{x}\ln(1 + x)}{x^2} \qquad \xi = e \\ \\ \\ \\
看到幂指函数，继续抬\,\, e\,\, \\ \\ \\
>\Large  \lim_{ x \to 0 }\,\, e^e \,\, \frac{{e^{\frac{1}{x}\ln(1+x)}-\frac{e}{x}\ln(1 + x)}}{x^2}  \\  \\  \\ 
> 看出指数表现形式和分子的减数一致，尝试\,\,麦克劳林
>  \\ \\ \\
>\large  \lim_{ x \to 0 }\,\, e^{e+1}\,\, \frac{{e^{\frac{1}{x}\ln(1+x)-1}-\left[ \frac{1}{x}\ln(1 + x)-1 \right] - 1}}{x^2}  \\ \\ \\
>\large\lim_{ x \to 0 } \frac{\,\,e^{e+1}}{2}\,\,\frac{{(\frac{1}{x}\ln(1+x)-1)^2}}{x^2}\\ \\  \\  
>再泰勒一次 \\  \\  \\
>\large \lim_{ x \to 0 } \,\, \frac{e^{e+1}}{2} \,\, \frac{{\left( x-\frac{x^2}{2}+O(x^2)-x \right)^2}}{x^4}
> \\ \\ \\
> 
>最终得出结果\,\,\,I=\frac{e^{e+1}}{8}
>
>\end{gather}
>$$


>[!bug] 拉格朗日中值定理
>$$
>\lim_{ x \to 0} \frac{{(e^{\sin x}+\tan x)^\frac{1}{x} -(e^{\tan x}+\sin x)^\frac{1}{x}}}{x^3}=?
>$$
>三重拉格朗日，最经典的一道
>$$
>\begin{gather}
>\lim_{ x \to 0 } \frac{e^{\frac{1}{x}\ln(e^{\sin x}+\tan x)}-e^{\frac{1}{x}\ln(e^{\tan x}+\sin x)}}{x^3} \\  \\
>拉中后 \,\,\,求解\,\,f^\prime(\xi)\,\,\,中的\,\,\xi\,\, 使用泰勒展开\\
>
>\\
>第一次拉中:\,\,\,\,\,\,\,\,\,\, 
>\lim_{ x \to 0 }  \frac{e^\xi\cdot[\ln(e^{\sin x}+\tan x)-\ln(e^{\tan x}+\sin x)]}{x^4} &&\xi=1 
>\\
>\\
>\\
>第二次拉中:\,\,\,\,\,\,\,\,\,\,\,\,\,
>\lim_{ x \to 0 } \frac{e  \cdot [e^{\sin x}+\tan x-e^{\tan x}-\sin x]}{\xi \cdot x^4}   &&  \xi=1 
>\\
>\\ 
>\\
>第三次拉中:\,\,\,\,\,\,\,\,\,\,\,\,\,
>\lim_{ x \to 0 } \frac{e\cdot(e^\xi-1) [\sin x-\tan x]}{x^4}   &&  \xi=x 
> \\
> \\
> \\
>泰勒展开:\,\,\,\,\,\,\,\,\,\,\lim_{ x \to 0 } \frac{e\cdot(1+x-1)( x-\frac{x^3}{6}-x-\frac{x^3}{3} )}{x^4}=-\frac{e^2}{2}
>
>
>\end{gather}
>$$
