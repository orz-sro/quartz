	 
解题过程：

1. 建立微分方程

由曲率公式：
$$K = \frac{|y''|}{(1+y'^2)^{3/2}}$$
题目给定：
$$K = \frac{1}{2y^2\cos\alpha}$$
其中 $\tan\alpha = y'$，则 $\cos\alpha = \frac{1}{\sqrt{1+y'^2}}$

代入得：
$$\frac{y''}{(1+y'^2)^{3/2}} = \frac{\sqrt{1+y'^2}}{2y^2}$$
化简：
$$2y^2 y'' = (1+y'^2)^2$$



2. 令 $w = y'^2$

则 $w' = 2y'y''$，方程变为：
$$\frac{dw}{(1+w)^2} = \frac{dy}{y^2}$$
积分：
$$\frac{1}{1+w} = \frac{1}{y} + C$$




3. 利用初始条件

曲线在 $(1,1)$ 取极小值 → $y(1)=1$，$y'(1)=0$（即 $w=0$）

代入得 $C=0$，所以：
$$\frac{1}{1+y'^2} = \frac{1}{y} \Rightarrow y'^2 = y-1$$




4. 解方程
$$\frac{dy}{\sqrt{y-1}} = dx$$
令 $u = \sqrt{y-1}$，得：
$$2\sqrt{y-1} = x + C$$
由 $y(1)=1$ 得 $C=-1$



5. 最终结果
$$\boxed{y = \frac{(x-1)^2}{4} + 1}$$
