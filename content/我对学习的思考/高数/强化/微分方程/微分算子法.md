# 引言：算子与特征值

微分算子法的底层逻辑：把求导当成**算子**（线性变换），函数当成"向量"——算子函数作用在特征函数上，直接代换特征值。

类比线性代数：$Av=\lambda v$ 中 $\lambda$ 是矩阵 $A$ 的**特征值**、$v$ 是**特征向量**。微积分里同样成立：把函数 $f(x)$ 看作"向量"，把线性变换 $xD$ 看作"算子"，它作用在单项式 $x^n$ 上：

$$\large (xD)\,x^n=x\cdot\frac{\mathrm{d}}{\mathrm{d}x}(x^n)=x\cdot nx^{n-1}=n\,x^n$$

结果正好是常数 $n$ 乘以 $x^n$ 本身——$x^n$ 是算子 $xD$ 的**特征函数**（相当于特征向量），指数 $n$ 是**特征值**。

比如 $xD\,x^2=2\,x^2$：这里的函数是 $x^2$（$n=2$），所以算子 $xD$ 作用在它上面的**特征值就是 $2$**。

于是任何由 $xD$ 构成的算子函数 $F(xD)$ 作用在 $x^2$ 上时，都可以把 $xD$ 直接替换成它的特征值 $2$：

$$\large F(xD)\,x^2=F(2)\,x^2$$

比如计算 $\dfrac{1}{xD+1}\,x^2$，算子函数是 $F(xD)=\dfrac{1}{xD+1}$，直接把特征值 $xD=2$ 代进去：

$$\large y^*=\frac{1}{xD+1}\,x^2=\frac{1}{2+1}\,x^2=\frac{1}{3}\,x^2$$

连积分都不用做，直接用特征值代换秒出特解，既优雅又不容易出错。

同样的思想就是后面**指数赋值**那招：$D\,e^{kx}=k\,e^{kx}$，$e^{kx}$ 是 $D$ 的特征函数、$k$ 是特征值

所以 $\dfrac{1}{F(D)}\,e^{kx}=\dfrac{1}{F(k)}\,e^{kx}$。

> [!tldr]  二阶常系数方程
> 
>
> 算 $\frac{1}{F(D)}$ 只需四招：**指数赋值、移位、长除法、三角赋 $D^2=-a^2$**；
> 
> 分母为零（共振）就**提 $x$**
> 
> 算子法覆盖约 90% 的常考右端项.


>[!info]  定义
$D$ 表示"求导"这个操作：$D^n$ 是 $n$ 阶求导，$\frac{1}{D}$ 是积分：
$$Dx=1,\quad Dx^2=2x,\quad D^2x^2=2,\qquad \frac{1}{D}x=\frac{1}{2}x^2$$
方程 $y''+py'+qy=f(x)$ 于是写成
$$\left(D^2+pD+q\right)y=f(x)$$
令 $F(D)=D^2+pD+q$，特解
$$\large y^*=\frac{1}{F(D)}f(x)$$


> [!hint] 为什么可以这样"除"
> $D$ 是"求导"操作本身：$D^2y=y''$、$pDy=py'$、$q$ 看成 $qD^0y$ 就是 $qy$。左边因数分解成 $F(D)$ 作用于 $y$，形式和代数方程一样了。
>
> **算子法的全部技巧就是：把 $F(D)$ 当普通多项式，按 $f(x)$ 的类型把它"除"掉。**
>
> 与特征方程的关系：$r^2+pr+q=0$ 就是把 $D$ 换成数 $r$ 的结果。

# 指数型

## 赋值

> [!quote] $e^{kx}$ 是 $D$ 的"特征向量"
> 对 $e^{kx}$ 求导还是 $e^{kx}$（只多乘一个 $k$），所以 $F(D)e^{kx}=F(k)e^{kx}$。倒过来就是——**把分母里的 $D$ 直接替换成特征值 $k$**，$e^{kx}$ 原样保留：
>
> $$\large \frac{1}{F(D)}e^{kx}=\frac{1}{F(k)}e^{kx}$$
> 
>> [!quote] 举例
$$\large \frac{1}{D^2+2D+1}e^x=\frac{1}{1+2+1}e^x=\frac{1}{4}e^x$$



## 共振

	$F(k)=0$  就提  x

1. 赋值后分母为零（$k$ 是特征根）时，**提一个 $x$，分母对 $D$ 求一次导，再赋值**：
   $$\large \frac{1}{F(D)}e^{kx}=x\cdot\frac{1}{F'(k)}e^{kx}$$
   
   例：$\large \frac{1}{D^2-3D+2}e^x$。  $F(1)=0$，$F'(D)=2D-3$，$F'(1)=-1$，故   $\large y^*=-xe^x$。


2. 若 $F'(k)=0$（$k$ 是重根），再提一个 $x$、分母求二阶导： 
 $$\large \frac{1}{F(D)}e^{kx}=x^2\cdot\frac{1}{F''(k)}e^{kx}$$
   
   例：$\large \frac{1}{(D-1)^2}e^x$。   $F''(D)=2$，故   $\large y^*=\frac{x^2}{2}e^x$。


> [!hint] 为什么提 $x$ 有用
> $F(k)=0$ 说明 $F(D)$ 有因子 $D-k$，而 $D-k$ 正好"杀死" $e^{kx}$。但 $(D-k)(xe^{kx})=e^{kx}$——于是 $\frac{1}{D-k}$ 作用在 $e^{kx}$ 上就"产出" $xe^{kx}$：**提一个 $x$ = 消掉一个零因子**；
> 
> **$k$ 是几重根，就提几个 $x$。**（和待定系数法重根乘 $x^r$ 是一回事）

# 多项式型

## 长除法

$f(x)$ 是 $n$ 次多项式：把 $\frac{1}{F(D)}$ 按 $D$ 的**升幂**（$1,\,D,\,D^2,\dots$）长除展开，**保留到 $D^n$ 项**，再逐项求导作用到 $f(x)$ 上。

例：$\large \frac{1}{D^2+2D+1}(x^2+2x)$。分母按升幂排 $1+2D+D^2$，长除：

$$\frac{1}{1+2D+D^2}=1-2D+3D^2+\cdots$$

逐项作用（$D(x^2+2x)=2x+2$，$D^2(x^2+2x)=2$）：

$$(1-2D+3D^2)(x^2+2x)=(x^2+2x)-2(2x+2)+3\cdot2=x^2-3x+2$$

> [!hint] 为什么只算到 $D^n$
> $n$ 次多项式求 $n$ 次以上导数是 $0$——**求导次数超过多项式次数就清零**，后面无穷多项全是白算。

	# 指数复合型

## 移位定理

$$\Large  e^{kx}\,\,g(x)$$
>[!quote]  注： $g(x)$  可以是 三角 或 多项式

指数乘别的函数时，把 $e^{kx}$ **整体提到前面**，分母里的 $D$ 换成 $D+k$，只算剩下的 $g(x)$：

$$\large \frac{1}{F(D)}\left[e^{kx}g(x)\right]=e^{kx}\frac{1}{F(D+k)}g(x)$$

> [!hint] 为什么是 $D+k$
> $D\left[e^{kx}g\right]=e^{kx}(D+k)g$：对乘积求导，$e^{kx}$ 每次被"拽"出来多出一个 $k$。反复运用，求导操作整体平移了 $k$。

例： $\large \frac{1}{D^2+1}xe^x$。

移位得   $\large e^x\frac{1}{(D+1)^2+1}x=e^x\frac{1}{D^2+2D+2}x$， 

长除 $\large \frac{1}{2+2D+D^2}=\frac{1}{2}(1-D+\cdots)$，作用于 $x$ 得 $\frac{1}{2}(x-1)$，故
$$\boxed{y^*=\frac{1}{2}e^x(x-1)}$$

# 三角型 

## 赋值

$D^2=-a^2$

$\large\sin (ax)$  求二阶导变号：$\large D^2\sin (ax)=-a^2\sin (ax)$，所以**把分母中的  $D^2$  换成  $-a^2$**

$$\large \frac{1}{F(D)}\sin ax=\frac{1}{F(-a^2)}\sin ax$$

>[!quote]  $\large \cos$ 与 $\large \sin$   的逻辑一致
>$$\large \frac{1}{D^2+4}\sin x=\frac{1}{-1+4}\sin x=\frac{1}{3}\sin x$$
>

>[!danger] 易错点
>
$\large\sin (ax)$  求一阶导：$\large D\sin (ax)= a\cos (ax)$
>
这里的 $D$ 不能等价于 a, 因为 等式左右三角函数并不相同



## 共振

$F(-a^2)=0$ 就提 $x$

和指数型同理，提一个 $x$、分母求导：

$$\large \frac{1}{F(D)}\sin ax=x\cdot\frac{1}{F'(D)}\sin ax$$

例：$\large \frac{1}{D^2+1}\sin x=x\cdot\frac{1}{2D}\sin x=\frac{x}{2}\int\sin x\,dx=-\frac{x}{2}\cos x$。

## 分母含 $D$ 一次项

上下同乘共轭，凑 $D^2$

>[!quote] 举例
>$$\large \frac{1}{D^2+2D+3}\sin x$$
>
$D^2=-1$：分母 $=2D+2=2(D+1)$, 分母不是 $D^2$ 的形，**上下同乘 $D-1$** 凑出 $D^2$
>
$$\frac{D-1}{2(D^2-1)}\sin x$$
>
再代入 $D^2=-1 \,\, \Longrightarrow \,\, \large \frac{D-1}{2(-2)}=-\frac{1}{4}(D-1)\sin x=-\frac{1}{4}(\cos x-\sin x)$。


> [!tldr] 三角型主线
> 所有技巧都围绕 $D^2=-a^2$：**能赋直接赋 → 赋完为零就提 $x$ → 有 $D$ 一次项就凑 $D^2$ 再赋**。

# 不适用： 三角 多项式

>[!quote] 多项式 × 三角
>
$f(x)=x\sin x\quad$    多项式 乘 三角函数的二阶常系数微分方程
>
算子法要动用欧拉公式（$\sin$ 写成复指数），越算越复杂——**直接用待定系数法**。




# 真题：2010 数一

求 $y''-3y'+2y=2xe^x$ 的通解。

齐次通解：$r^2-3r+2=0\Rightarrow r=1,\,2$，$y_0=C_1e^x+C_2e^{2x}$。

算子法求特解（$k=1$ 是特征根、指数又带 $x$，所以移位）：

$$y^*=\frac{1}{D^2-3D+2}2xe^x=2e^x\frac{1}{(D+1)^2-3(D+1)+2}x=2e^x\frac{1}{D^2-D}x$$

对 $\frac{1}{D^2-D}$ 长除（升幂排 $-D+D^2$）：

$$\frac{1}{-D+D^2}=-\frac{1}{D}\cdot\frac{1}{1-D}=-\frac{1}{D}\left(1+D+D^2+\cdots\right)=-\left(\frac{1}{D}+1+D+\cdots\right)$$

$x$ 是一次多项式，保留到 $D^1$ 项，作用于 $x$：

$$-\left(\frac{1}{D}+1+D\right)x=-\left(\frac{x^2}{2}+x+1\right)$$

故 $y^*=2e^x\cdot\left[-\left(\frac{x^2}{2}+x+1\right)\right]=-e^x(x^2+2x+2)$。


$$\large y=C_1e^x+C_2e^{2x}-e^x(x^2+2x+2)=\boxed{(C_1-2)e^x+C_2e^{2x}-e^x(x^2+2x)}$$


> [!tip] 卷面书写技巧
> 算子法**不在考纲**。解答题建议：卷面设特解形式 $y^*=e^x(ax^2+bx)$（待定系数法写法），草稿纸上用算子法瞬间算出 $a=-1,\,b=-2$，卷面直接写"解得 $a=-1,\,b=-2$"，避免步骤争议。
>
> 现在大题很少单独考二阶常系数求解，多是变限积分、级数或几何应用里的一小步，**只要算对结果就行，不必写详细步骤**——这正是算子法的用武之地。




# 选择题

例 1（660）：$y''+y=\cos kx$ 的特解可能具有什么形式？

$$y^*=\frac{1}{D^2+1}\cos kx=\frac{1}{1-k^2}\cos kx$$

$k^2\ne1$：分母非零，$y^*=A\cos kx$（纯三角函数、无 $x$）；$k^2=1$：共振，$y^*=x\cdot\frac{1}{2D}\cos x=\frac{x}{2}\sin x$（形式 $x(A\cos x+B\sin x)$）。

**看到选项里只有带 $x$ 的才可能成立 → 必是共振 $k^2=1$ → 直接选 $x\sin x$ 那个。**




例 2（660）：$y''-2y'+5y=e^x\cos2x$ 的特解形式？

$$y^*=\frac{1}{D^2-2D+5}e^x\cos2x=e^x\frac{1}{(D+1)^2-2(D+1)+5}\cos2x=e^x\frac{1}{D^2+4}\cos2x$$

赋 $D^2=-4$：分母 $-4+4=0$，共振 → 提 $x$：

$$y^*=xe^x\cdot\frac{1}{2D}\cos2x=\frac{x}{2}e^x\cdot\frac{1}{2}\sin2x=\frac{x}{4}e^x\sin2x$$

形式    $xe^x(A\cos2x+B\sin2x)$   秒选


# 高代视角

算子法不是四招拼凑，它整套就是**线性代数**：$D$ 是函数空间上的线性变换，$e^{kx}$ 是它的特征向量，特征方程 $F(\lambda)=0$ 里的 $\lambda$ 正是 $D$ 的特征值。四招本质是同一件事——**在特征向量（及广义特征向量）基底上，把 $F(D)$ 化成数乘，求逆化成除法**。

| 线性代数 | 算子法 |
| --- | --- |
| 矩阵 $A$ | 算子 $D$（求导是线性变换） |
| 特征值 $\lambda$ | $k$：$De^{kx}=ke^{kx}$ |
| 特征多项式 $\lvert\lambda I-A\rvert$ | $F(\lambda)=\lambda^2+p\lambda+q$ |
| 对角化 → 数乘 $\lambda$ | 赋值 → 数乘 $F(k)$ |
| $A$ 奇异（不可逆） | 共振：$F(k)=0$ |
| 零空间 $\ker A$ | 齐次解空间 $\ker F(D)$ |
| 约当链 / 广义特征向量 | 提 $x$：$(D-k)(xe^{kx})=e^{kx}$ |
| $(I-A)^{-1}=\sum A^n$ | 长除法（$D$ 在多项式上幂零） |
| $Ax=b$ 解集 $x_0+\ker A$ | 通解 $y^*+$ 齐次通解（特解不唯一） |

**赋值 = 对角化**：在 $e^{kx}$ 这个"方向"上，$D$ 就是乘 $k$——$e^{kx}$ 是 $D$ 的"特征方向"，$k$ 是"对角元"。
用线代的话说,"能不能取数值形式"的条件,就是**这个函数是不是 D 的特征函数**——是,就能取数值形式(数值就是对应的特征值);不是,就看做普通的求导



于是 $F(D)$ 作用在 $e^{kx}$ 上就是乘 $F(k)$，求逆就是除以 $F(k)$——和**对角矩阵求逆 = 对角元取倒数**是同一件事。

**共振 = 奇异，提 $x$ = 约当链**：$F(k)=0$ 时 $e^{kx}\in\ker F(D)$，算子不可逆。但 $(D-k)(xe^{kx})=e^{kx}$：$xe^{kx}$ 是广义特征向量，$e^{kx}\to xe^{kx}\to\frac{x^2}{2}e^{kx}$ 是一条**约当链**，$(D-k)$ 在链上"爬一格"、$\frac{1}{D-k}$"退一格"。**重根几重、链就多长，所以提几个 $x$。**

**移位 = 谱平移**：$e^{-kx}De^{kx}=D+k$——乘以 $e^{kx}$ 相当于换基底，新基底里 $D$ 的特征值整体平移 $k$。移位定理就是"谱平移之后再求逆"。

**长除 = 几何级数**：把分母按升幂提常数因子后，求逆就是 $1+T$ 的"几何级数"：

$$\large \frac{1}{a_0+a_1D+\cdots}=\frac{1}{a_0}\cdot\frac{1}{1+T}=\frac{1}{a_0}\left(1-T+T^2-\cdots\right),\qquad T=\frac{a_1}{a_0}D+\cdots$$

$D$ 在 $n$ 次多项式上是**幂零算子**（$D^{n+1}$ 清零），级数在 $D^n$ 项后自然截断——"只算到 $D^n$"不是偷懒，是幂零性。

**三角 = 复特征向量**：$\sin ax=\frac{e^{iax}-e^{-iax}}{2i}$ 是特征值 $\pm ia$ 的特征向量组合，$D^2$ 在它们上面都是 $-a^2$。

所以"赋 $D^2=-a^2$"仍是特征值代入；共振 ⟺ $\pm ia$ 是特征根。

> [!quote] 一句话本质
> 求导是线性变换 ⟹ $F(D)y=f$ 是"线性方程组"；
> 
> $e^{kx}$ 是特征向量 ⟹ "除以 $F(D)$"就是"除以 $F(k)$"；
> 
> 共振 = 特征值撞上 $F$ 的零点，沿约当链取"广义逆"。
> 
> **特征方程的名字就是这么来的**——它就是算子的特征值方程。
> 
> 2010 真题里特解"差一个齐次解分量"（$C_1-2$ 那个合并）也正是 $x_0+\ker A$ 的解集结构。
