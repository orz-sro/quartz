## 易错点


$$\Large \int_0^{\pi} \dfrac{dx}{1+\sin^2 x}$$


> [!hint] 用 N-L 前必须确认：原函数在整个积分区间上连续
>

---

### 错误解法

$$\large \int_0^{\pi} \frac{dx}{1+\sin^2 x} = \int_0^{\pi} \frac{d(\tan x)}{2\tan^2 x+1} = \frac{1}{\sqrt{2}}\Big[\arctan(\sqrt{2}\tan x)\Big]_0^{\pi} = 0 \quad \color{red}{\times}$$

> [!bug] 错因
> $\large \tan x$ 在   $x=\dfrac{\pi}{2}$   处无定义，导致
> $$\large \arctan(\sqrt{2}\tan x)$$
> 在该点跳跃（左右极限相差 $\pi$），**不是**被积函数在 $[0,\pi]$ 上的原函数，不能直接套 N-L 公式。
> 
> 被积函数 $\dfrac{1}{1+\sin^2 x}$ 本身连续有界，积分合法
> 

---

### 正确解法

#### 解法一：对称折半

被积函数满足 $\large f(\pi - x) = f(x)$，将区间折半，把间断点退到端点再取极限：

$$\large \int_0^{\pi} \frac{dx}{1+\sin^2 x} = 2\int_0^{\frac{\pi}{2}} \frac{d(\tan x)}{2\tan^2 x+1} = \sqrt{2}\left[\arctan(\sqrt{2}\tan x)\right]_0^{\frac{\pi}{2}^-} = \dfrac{\sqrt{2}\,\pi}{2}$$

> [!tip] 关键 端点处取**极限值**而非函数值（反常积分思想）。

#### 解法二：移轴换元


令  $\large x = t + \dfrac{\pi}{2}$，区间平移为  $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$，$\sin^2 x = \cos^2 t$，间断点直接消失：

$$\large \int_0^{\pi} \frac{dx}{1+\sin^2 x} = 2\int_0^{\frac{\pi}{2}} \frac{dt}{1+\cos^2 t} = 2\int_0^{\frac{\pi}{2}} \frac{d(\tan t)}{2+\tan^2 t} = \dfrac{\sqrt{2}\pi}{2}$$

$$\boxed{\dfrac{\sqrt{2}\pi}{2}}$$

# 定积分的换元法

## 第二类换元

**不定积分** 有两类换元法；**定积分的换元法只有一种** 二类换元


令 $\large x = \varphi(t)$，上下限跟着换

$$\large \int_a^b f(x)\,dx = \int_\alpha^\beta f[\varphi(t)]\varphi'(t)\,dt$$

**换元条件**：

1. $\large \varphi(\alpha) = a$，$\large \varphi(\beta) = b$

2. $\large \varphi(t)$ 在 $\large [\alpha,\beta]$（或 $\large [\beta,\alpha]$）上具有**连续导数**，且值域 $\large R_\varphi \subset [a,b]$


**教材脚注（同济 246 页）**：当值域 $R_\varphi$ 超出 $[a,b]$ 时，只要 $f(x)$ 在 $R_\varphi$ 上**连续**，定理结论仍然成立。

>[!danger] 定理从头到尾没有"单调"二字
> 不定积分第二类换元必须单调，是因为算完要**回代**  $\large t = \psi^{-1}(x)$ ，反函数得存在。
> 
> 定积分换完上下限直接代新限出数值，**永不回代**，所以不需要反函数，也就不需要单调。
>
> ***换元函数必须单调***  是充分不必要条件，是保险写法，不是定理要求。

## 单调性问题

>[!example] 举例
>$$
>\large \int_0^{\frac{\sqrt{2}}{2}} 4x\,dx
>$$

法一：直接积，答案为 $1$（原函数 $\large 2x^2$）。 


法二：令 $\large x = \sin t$ ，上限有两种取法：

- 上限取 $\dfrac{\pi}{4}$：$x=\sin t$ 在 $\left[0,\dfrac{\pi}{4}\right]$ 单调，值域恰好是 $\left[0,\dfrac{\sqrt2}{2}\right]$

- 上限取 $\dfrac{3\pi}{4}$：$x=\sin t$ 在 $\left[0,\dfrac{3\pi}{4}\right]$ **不单调**，$t$ 走到中间时 $x$ 先冲到 $1$ 再折回 $\dfrac{\sqrt2}{2}$
  值域 $\left[0,1\right]$ **超出**了原区间


$$\large \int_0^{\frac{3\pi}{4}} 4\sin t\cos t\,dt = \Big[2\sin^2 t\Big]_0^{\frac{3\pi}{4}} = 2\left(\frac{\sqrt2}{2}\right)^2 = 1$$

两种上限算出同样的 $1$。谁规定 $\dfrac{\sqrt2}{2}$ 必须对应 $\dfrac{\pi}{4}$？端点对应即可，中途可以绕远越界

> $\large f$ 在扩大的值域上连续就行



### 反函数的定义域

>[!danger] 只能"令 x = ..."，不能"令 ... = t"

看到  $\large \sin x$  想令  $\large \sin x = t$  时，必须先反解成  $\large x = \varphi(t)$。 

而  $\large \sin$  的反函数在不同单调段表达式不同：

$$

\begin{gather}
	\large x \in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]\quad 则\ \  x = \arcsin t \\ \\ \\
	 \large x \in\left[\frac{\pi}{2},\frac{3\pi}{2}\right]\quad 则 \ \ x = \pi - \arcsin t
\end{gather}
$$


>[!example] 陷阱题
>$$
>\large \int_0^{\pi} \sin x\,dx = 2,\quad \text{但令 } \sin x = t \text{ 后上下限都变成 } 0,\ \int_0^0 = 0\ ?
>$$

错因：$x$ 从 $0$ 走到 $\pi$ **横跨两个单调段**，一个反解式子覆盖不了全程，必须拆段：

$$\large \int_0^{\pi} \sin x\,dx = \int_0^{\frac{\pi}{2}} \sin x\,dx + \int_{\frac{\pi}{2}}^{\pi} \sin x\,dx$$

第一段反解  ${\color{skyblue}\large x = \arcsin t}$，第二段反解  ${\color{skyblue}\large x = \pi - \arcsin t}$，各自换元后相加，结果为 $2$

"令 $\sin x = t$" 一个式子想吞掉整个 $[0,\pi]$，上下限同时落到 $t=0$，这就是 $99\%$ 的人踩的坑。真要省事，用对称性 $\int_0^\pi \sin x\,dx = 2\int_0^{\frac{\pi}{2}}\sin x\,dx$ 反而一步到位。

# 托里尼悖论

> [!hint]  Gabriel's Horn（加百列号角）
> 一个 <font color="#d99694">**体积有限**</font>、<font color="#d99694">**表面积无穷大**</font> 的旋转体。
> 你可以用有限的油漆**灌满**它，却永远无法**涂满**它的内壁。

## 经典模型

曲线 $y = \dfrac{1}{x}$（$x \geq 1$）绕 $x$ 轴旋转：

$$\large V = \pi\int_1^{+\infty}\frac{1}{x^2}\,dx = \pi \quad \color{#7ee787}{\text{（有限）}}$$

$$\large S = 2\pi\int_1^{+\infty}\frac{1}{x}\sqrt{1+\frac{1}{x^4}}\,dx \geq 2\pi\int_1^{+\infty}\frac{1}{x}\,dx = +\infty \quad \color{#ff7b72}{\text{（发散）}}$$

求体积时被积函数是 $\dfrac{1}{x^2}$（$p=2>1$，收敛）,  求面积时被积函数主项是 $\dfrac{1}{x}$（$p=1$，发散）

---

## 维度分析

同一条曲线  $y = \dfrac{1}{x}$，逐维度看：

| 维度 | 量 | 敛散 |
|:---:|---|:---:|
| 1D | 弧长 | <font color="#ff7b72">发散</font> |
| 2D | 曲线下面积 | <font color="#ff7b72">发散</font> |
| 2D | 旋转体侧面积 | <font color="#ff7b72">发散</font> |
| 3D | 旋转体体积 | <font color="#7ee787">**收敛**</font> |

> [!tip] 悖论核心
> 实际是因为 面积 并不能和 体积 同时比较，一个是有厚度的三维体 ，另一个仅是二维面，实际上，再大的二维图形也没有三维图中一个点 大，因为其受到维度的约束

## 2010 真题

区域 $G$：$y = \dfrac{1}{\sqrt{x(1+\ln^2 x)}}$（$e \leq x < +\infty$）下方、$x$ 轴上方的无界区域。

**面积**

$\displaystyle\int_e^{+\infty}\frac{1}{\sqrt{x(1+\ln^2 x)}}\,dx$，由于 $\dfrac{1}{\sqrt{x(1+\ln^2 x)}} \geq \dfrac{1}{\sqrt{x}(1+\ln x)}$ 且后者发散，故面积 <font color="#ff7b72">发散</font>。

**体积**

$$\large V = \pi\int_e^{+\infty}\frac{1}{x(1+\ln^2 x)}\,dx = \pi\int_e^{+\infty}\frac{d(\ln x)}{1+\ln^2 x} = \pi\arctan(\ln x)\Big|_e^{+\infty} = \frac{\pi^2}{4}$$

> [!hint] 注意
> 面积公式里 $f(x)$ 含 $\dfrac{1}{\sqrt{x}}$（$p=\frac{1}{2}<1$，发散），体积公式里 $[f(x)]^2$ 含 $\dfrac{1}{x}$——再多除一个 $\ln^2 x$ 的修正项使之收敛，完美对应托里尼悖论的结构。









# 物理应用

>[!error] 一元定积分在物理学中的应用本质上是微元法（元素法）的具体体现

![[Pasted image 20260915142916.png]]

**1. 建立坐标系与压力微元**

- **建系**：以水面为 $y$ 轴，铅直向下为 $x$ 轴。半圆方程为 $x^2 + y^2 = R^2$。
    
- **取微元**：在深度 $x$ 处取厚度为 $dx$ 的水平窄长条。
    
    - 压强：$p = \rho g x$
        
    - 面积：$dA = 2y \, dx = 2\sqrt{R^2 - x^2} \, dx$
        
- **微元表达式**：
    
    $$dF = p \cdot dA = 2\rho g x \sqrt{R^2 - x^2} \, dx$$
    

**2. 积分计算总压力**

受力范围为 $x \in [0, R]$，利用凑微分 $2x \, dx = -d(R^2 - x^2)$ 求解：

$$F = \int_0^R 2\rho g x \sqrt{R^2 - x^2} \, dx$$

$$F = -\rho g \int_0^R (R^2 - x^2)^{\frac{1}{2}} \, d(R^2 - x^2)$$

$$F = -\rho g \left[ \frac{2}{3} (R^2 - x^2)^{\frac{3}{2}} \right]_0^R = \frac{2}{3} \rho g R^3$$
