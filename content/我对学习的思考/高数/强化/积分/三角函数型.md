# 常用三角积分公式

## 基本公式

$$\large \int \tan x\,dx = -\ln|\cos x| + C \qquad\quad \int \cot x\,dx = \ln|\sin x| + C$$

$$\large \int \sec x\,dx = \ln|\sec x + \tan x| + C \qquad \int \csc x\,dx = \ln|\csc x - \cot x| + C$$

$$\large \int \sec^2 x\,dx = \tan x + C \qquad\qquad\ \ \int \csc^2 x\,dx = -\cot x + C$$

$$\large \int \sec x \tan x\,dx = \sec x + C \qquad\qquad \int \csc x \cot x\,dx = -\csc x + C$$



$\large sec、\csc$  只需记一个推导：


$$\large \int \sec x\,dx = \int \dfrac{\sec x(\sec x + \tan x)}{\sec x + \tan x}\,dx = \ln|\sec x + \tan x| + C$$

## 降幂型


$$\large \int \sin^2 x\,dx = \frac{x}{2} - \frac{\sin 2x}{4} + C \qquad\quad \int \cos^2 x\,dx = \frac{x}{2} + \frac{\sin 2x}{4} + C$$

$$\large \int \tan^2 x\,dx = \tan x - x + C \qquad\qquad\ \ \int \cot^2 x\,dx = -\cot x - x + C$$

$$\large \int \frac{dx}{\sin x\cos x} = \int \frac{2\,dx}{\sin 2x} = \ln|\tan x| + C$$





## 分母齐次型


$$\large \int \frac{dx}{a^2\cos^2 x + b^2\sin^2 x} = \frac{1}{ab}\arctan\frac{b\tan x}{a} + C \qquad (a, b > 0)$$

$$\large \int \frac{dx}{a^2\sin^2 x - b^2\cos^2 x} = \frac{1}{2ab}\ln\left|\frac{a\tan x - b}{a\tan x + b}\right| + C \qquad (a, b > 0)$$


套路：分子分母同除   $\large \cos^2 x$，  $凑\,\,\,{\color{skyblue}\large \sec^2 x\,dx = d(\tan x)}$

 $$\large 化为：\int \dfrac{du}{\pm a^2u^2 \pm b^2}$$





## 乘共轭


$\large 1 \pm \sin x,\ 1 \pm \cos x$ 型（乘共轭）

$$\large \int \frac{dx}{1+\cos x} = \tan\frac{x}{2} + C \qquad\qquad \int \frac{dx}{1-\cos x} = -\cot\frac{x}{2} + C$$

$$\large \int \frac{dx}{1+\sin x} = \tan x - \sec x + C \qquad \int \frac{dx}{1-\sin x} = \tan x + \sec x + C$$



记忆：乘共轭把分母变成完全平方，如    $\dfrac{1}{1+\sin x} = \dfrac{1-\sin x}{\cos^2 x} = \sec^2 x - \sec x\tan x$

# 万能代换 


$$\large 代换因子\qquad t = \tan\dfrac{x}{2}$$

$$\large \sin x = \frac{2t}{1+t^2} \qquad \cos x = \frac{1-t^2}{1+t^2} \qquad \tan x = \frac{2t}{1-t^2} \qquad dx = \frac{2\,dt}{1+t^2}$$

任何   $\large \sin x, \cos x$   的有理式都能化为  $\large t$  的有理函数，是三角有理式积分的**通法**。

但计算量大，属于没办法时的最后手段——优先考虑拆分、共轭、辅助角等巧法。

## 典例


$$\int \dfrac{dx}{a + b\cos x}$$

$$\large \int \frac{dx}{a + b\cos x} = \frac{2}{\sqrt{a^2-b^2}}\arctan\left(\sqrt{\frac{a-b}{a+b}}\tan\frac{x}{2}\right) + C \qquad (a^2 > b^2)$$


$$\large \int \frac{dx}{a + b\cos x} = \frac{1}{\sqrt{b^2-a^2}}\ln\left|\frac{a+b+\sqrt{b^2-a^2}\tan\frac{x}{2}}{a+b-\sqrt{b^2-a^2}\tan\frac{x}{2}}\right| + C \qquad (a^2 < b^2)$$

$\int \dfrac{dx}{a + b\sin x}$ 完全同理。

## 举例

>[!example] 题一
>$$
>\large \int \dfrac{dx}{2+\sin x}
>$$

设 $t = \tan\dfrac{x}{2}$，代入万能公式：

$$\large \int \frac{dx}{2+\sin x} = \int \frac{\frac{2\,dt}{1+t^2}}{2+\frac{2t}{1+t^2}} = \int \frac{dt}{t^2+t+1} = \int \frac{dt}{\left(t+\frac{1}{2}\right)^2+\frac{3}{4}}$$

$$\large = \frac{2}{\sqrt{3}}\arctan\frac{2t+1}{\sqrt{3}} + C = \frac{2}{\sqrt{3}}\arctan\frac{2\tan\frac{x}{2}+1}{\sqrt{3}} + C$$

# 线性组合拆分

分子分母都是  $\large \sin x, \cos x$  的线性组合时，把分子拆成   ${\color{skyblue}A} \cdot$ 分母 $+\, {\color{gold}B}  \cdot$ 分母的导数，积分变成 $\large Ax + B\ln|\text{分母}|$。

## 通用方法

$$
\begin{gather}
	 & \Large \int \frac{a\sin x + b\cos x}{c\sin x + d\cos x}\,dx \\
	 \\ \\
	 & \Large \text{设} \ \    a\sin x + b\cos x = A\underbrace{(c\sin x + d\cos x)}_{\text{分母}} + B\underbrace{(c\cos x - d\sin x)}_{\text{分母的导数}}
\end{gather}
$$

比较 $\sin x, \cos x$ 的系数解出 $A, B$，则

$$\large \int \frac{a\sin x + b\cos x}{c\sin x + d\cos x}\,dx = Ax + B\ln|c\sin x + d\cos x| + C$$


> 特例：分子恰好是分母的导数时 $A=0$，直接得 $\ln|\text{分母}|$。

## 举例

>[!example] 题一
>$$
>\large \int \dfrac{\sin x}{\sin x + \cos x}\,dx
>$$

设  $\sin x = A(\sin x + \cos x) + B(\cos x - \sin x)$，比较系数：

$$\large \begin{cases} A - B = 1 \\ A + B = 0 \end{cases} \implies A = \frac{1}{2},\quad B = -\frac{1}{2}$$

$$\large \int \frac{\sin x}{\sin x + \cos x}\,dx = \frac{x}{2} - \frac{1}{2}\ln|\sin x + \cos x| + C$$


>[!example] 题二
>$$
>\large \int \dfrac{2\sin x + \cos x}{\sin x + \cos x}\,dx
>$$

设  $2\sin x + \cos x = A(\sin x + \cos x) + B(\cos x - \sin x)$：

$$\large \begin{cases} A - B = 2 \\ A + B = 1 \end{cases} \implies A = \frac{3}{2},\quad B = -\frac{1}{2}$$

$$\large \int \frac{2\sin x + \cos x}{\sin x + \cos x}\,dx = \frac{3x}{2} - \frac{1}{2}\ln|\sin x + \cos x| + C$$



## 分子为常数 ,此法失效

$\int \dfrac{dx}{a\sin x + b\cos x}$ 的分子是 $1$，凑不出线性组合。改用辅助角：

$$\large a\sin x + b\cos x = \sqrt{a^2+b^2}\,\sin(x+\varphi),\qquad \tan\varphi = \frac{b}{a}$$

$$\large \int \frac{dx}{a\sin x + b\cos x} = \frac{1}{\sqrt{a^2+b^2}}\ln\left|\tan\frac{x+\varphi}{2}\right| + C$$

# 方法选择顺序

1. 分母 二次齐次：同除 $\large \cos^2 x$，凑 $\large d(\tan x)$

2. 分子分母线性组合：拆成 $A\cdot 分母$ $+ \,B\cdot {\large{d}}(分母)$

3. $\large 1\pm\sin x,\ 1\pm\cos x$： 乘共轭

4. 分子为常数的一次式：辅助角化 $\large \csc$ 型

5. 万能代换兜底
