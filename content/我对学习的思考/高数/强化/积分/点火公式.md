# 初阶公式

点火公式，即华里士（Wallis）公式，专门处理 $\large [0, \frac{\pi}{2}]$ 上 $\large \sin^n x$ 与 $\large \cos^n x$ 的积分：

$$\large \int_0^{\frac{\pi}{2}} \sin^n x\,dx = \int_0^{\frac{\pi}{2}} \cos^n x\,dx = \begin{cases} \large \dfrac{(n-1)!!}{n!!}\cdot\dfrac{\pi}{2} & \large n\ \text{偶} \\[2mm] \large \dfrac{(n-1)!!}{n!!} & \large n\ \text{奇} \end{cases}$$

其用法十分简明：从 $\large n$ 出发，隔项相乘，逐级递降。

递降至链末，未点及 $\large 1$ 者，不必另行处理；点及 $\large 1$ 者，则补乘 $\large \dfrac{\pi}{2}$。

- $\large n$ 为偶数时，分子止于 $\large 1$，故补乘 $\large \dfrac{\pi}{2}$

- $\large n$ 为奇数时，分子止于 $\large 2$，无须补乘

$$\large \int_0^{\frac{\pi}{2}}\sin^6 x\,dx = \frac{5}{6}\cdot\frac{3}{4}\cdot\frac{1}{2}\cdot\frac{\pi}{2} = \frac{5\pi}{32}$$

$$\large \int_0^{\frac{\pi}{2}}\sin^7 x\,dx = \frac{6}{7}\cdot\frac{4}{5}\cdot\frac{2}{3} = \frac{16}{35}$$

## 本质

这一公式并非需要死记的硬性规定，其来源只是一次分部积分。记 $\large I_n = \int_0^{\frac{\pi}{2}} \sin^n x\,dx$，分出一个 $\large \sin x$ 凑到微分号内：

$$\large I_n = \int_0^{\frac{\pi}{2}} \sin^{n-1}x\,\sin x\,dx = -\int_0^{\frac{\pi}{2}} \sin^{n-1}x\,d(\cos x)$$

分部积分。边界项在两端皆为零（$\large x = \frac{\pi}{2}$ 处 $\large \cos x = 0$，$\large x = 0$ 处 $\large \sin^{n-1}x = 0$）：

$$\large I_n = \underbrace{-\sin^{n-1}x\cos x\Big|_0^{\frac{\pi}{2}}}_{=\,0} + (n-1)\int_0^{\frac{\pi}{2}} \cos^2 x\,\sin^{n-2}x\,dx$$

$$\large = (n-1)\int_0^{\frac{\pi}{2}} (1-\sin^2 x)\,\sin^{n-2}x\,dx$$

后一项拆开，恰为 $\large I_{n-2}$ 与 $\large I_n$ 本身，移项即得递推公式：

$$\large I_n = (n-1)\,(I_{n-2} - I_n) \implies n\,I_n = (n-1)\,I_{n-2} \implies I_n = \frac{n-1}{n}\,I_{n-2}$$

照此递推下去，终点只有两种归宿：$\large n$ 为偶数者止于 $\large I_0 = \dfrac{\pi}{2}$，$\large n$ 为奇数者止于 $\large I_1 = 1$，口诀中“点到几”所指即此。

至于 $\large \sin$ 与 $\large \cos$ 为何同值，只需换元 $\large x = \dfrac{\pi}{2} - t$（即[[区间再现]]），二者便互相转化，无需另证。

# 广义公式

前述只处理单一的 $\large \sin^n x$ 或 $\large \cos^n x$；当二者相乘，即 $\large \sin^m x\,\cos^n x$ 型积分，则用下面的特殊华里士公式：

$$\large \int_0^{\frac{\pi}{2}} \sin^m x\,\cos^n x\,dx = \begin{cases} \large \dfrac{(m-1)!!\,(n-1)!!}{(m+n)!!}\cdot\dfrac{\pi}{2} & \large m,\ n\ \text{均为偶数} \\[2mm] \large \dfrac{(m-1)!!\,(n-1)!!}{(m+n)!!} & \large \text{其余情形} \end{cases}$$

用法与初阶一致：分母按 $\large m + n$ 隔项递降，分子取 $\large m$ 与 $\large n$ 各自的隔项链；仅当 $\large m$、$\large n$ 均为偶数时补乘 $\large \dfrac{\pi}{2}$。

## 举例

$$\large \int_0^{\frac{\pi}{2}} \sin^2 x\,\cos^3 x\,dx = \frac{1!!\cdot 2!!}{5!!} = \frac{2}{15}$$

$$\large \int_0^{\frac{\pi}{2}} \sin^2 x\,\cos^2 x\,dx = \frac{1!!\cdot 1!!}{4!!}\cdot\frac{\pi}{2} = \frac{\pi}{16}$$

# 其他区间

点火公式仅对 $\large [0, \frac{\pi}{2}]$ 直接成立；区间扩大时，先依对称性与周期性折算：

- $\large [0, \pi]$：$\large \sin^n x$ 恒为狭义的 $\large 2$ 倍；$\large \cos^n x$ 偶次 $\large 2$ 倍，奇次为 $\large 0$

- $\large [0, 2\pi]$ 与 $\large [-\pi, \pi]$：偶次为狭义的 $\large 4$ 倍，奇次为 $\large 0$

- $\large [-\frac{\pi}{2}, \frac{\pi}{2}]$：$\large \cos^n x$ 恒为狭义的 $\large 2$ 倍；$\large \sin^n x$ 偶次 $\large 2$ 倍，奇次为 $\large 0$

总而言之：**倍数由区间决定，归零由奇偶判定。**

## 举例

$$\large \int_0^{\pi} \sin^4 x\,dx = \pi\cdot\frac{3!!}{4!!} = \frac{3\pi}{8}$$

$$\large \int_0^{2\pi} \cos^6 x\,dx = 2\pi\cdot\frac{5!!}{6!!} = \frac{5\pi}{8}$$

被积函数若含 $\large kx + b$，应先换元，视新的积分限落于何处，再依上述规则处理：

$$\large \int_0^{\pi} \sin^4 2x\,dx \xrightarrow{\ \large t\,=\,2x\ } \frac{1}{2}\int_0^{2\pi} \sin^4 t\,dt = \frac{1}{2}\cdot 2\pi\cdot\frac{3!!}{4!!} = \frac{3\pi}{8}$$

# 易错

- 双阶乘须分辨奇偶：$\large 6!! = 48$，$\large 7!! = 105$；约定 $\large 0!! = 1$

- $\large n$ 为 $\large 0$ 或 $\large 1$ 时已无可点之式，其值分别为 $\large \dfrac{\pi}{2}$ 与 $\large 1$
