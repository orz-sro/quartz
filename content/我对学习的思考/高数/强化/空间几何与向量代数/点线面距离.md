# 点线间距离

> [!hint] 点线间距离公式
$$
	 \large d = \frac{{|Ax_{0} + B y_{0} + C|}}{\sqrt{ A^2 + B^2}}
$$
需要注意的是 直线  $Ax + By + C= 0$ 中，$(A,B)$ 是 $l$ 的法向量，不是方向向量

> 证明 $(A, \ B)$ 是 直线法向量

已知  $A \ x_{0} + B\ y_{0}+C = 0$，$A \ x + B\ y+C = 0$  ；两式相减得    $(A, \ B) ·(x - x_{0}, \ y - y_{0}) = 0$
